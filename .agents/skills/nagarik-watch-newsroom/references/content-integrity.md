# Content integrity

## Demo and seed content

Demo content must be unmistakably non-production. Use one of these patterns:

- verified public-source summary with source name, source URL, source publication time, retrieval time, and rewritten original summary
- evergreen explainer with named official references
- clearly labeled fictional fixture used only in tests and excluded from public builds

Never attach a staff byline to reporting the newsroom did not perform. Use a desk attribution such as “नागरिक वाच डेस्क” only for properly sourced summaries and label the source type.

Do not invent direct quotes. Paraphrase and link to the primary source.

## Recommendation exclusions

Always exclude retracted, unpublished, future-dated, expired, sensitive-without-eligibility, sponsored-without-label, and `doNotRecommend` content. Penalize repeated topics and sources. Log the dominant reason and model/version for audit.

## Freshness

Treat publish time, update time, source time, and ingestion time as separate fields. Do not rewrite source publication times to make content appear fresh.
