# Taxonomy fixtures only

This directory contains development taxonomy and author fixtures. It must not contain invented current-affairs articles.

For reader-visible content, use one of these paths:

1. Original reporting created in Payload CMS with a real byline and editorial workflow.
2. Licensed wire content with the required source fields.
3. Headline-and-link RSS items on the public Source Desk; never copy the upstream body or image.

The former June 2026 article fixtures were removed because they mixed real-world subjects with unverified quotes, bylines, and details.
