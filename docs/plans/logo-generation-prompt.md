# Nagarik Watch Logo Generation Prompt

Use this prompt in an image model that can produce transparent PNG logos:

Create a professional transparent-background PNG logo for "Nagarik Watch" / "नागरिक वाच", a civic Nepali news portal. The mark should combine a watchful human eye and Himalayan mountain peaks in a clean, ownable symbol. Use civic navy, deep crimson and a restrained warm gold accent. The mark must work at favicon size and as a horizontal masthead lockup. Avoid stock shield icons, AI-gloss, 3D mockups, gradients, glass effects, fake phone previews, flags, eagles, generic news microphones and copied brand-board shapes. Produce a flat vector-like logo with crisp negative space, strong silhouette, balanced Devanagari and Latin wordmark options, and no background.

Preferred palette:

- Navy: #001F5B
- Crimson: #ED1B24
- Gold accent: #FFD700
- Warm neutral off-white when needed, not pure white.

Deliverables:

1. Icon-only mark, transparent PNG, 1024x1024.
2. Horizontal lockup with English wordmark, transparent PNG, 2400x800.
3. Horizontal lockup with Devanagari-first wordmark, transparent PNG, 2400x800.
4. Single-color navy version, transparent PNG.
