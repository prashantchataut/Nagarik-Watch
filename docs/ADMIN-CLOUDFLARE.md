# Admin + full app hosting

## Live now

| Surface | URL | Host |
|---------|-----|------|
| **Full app** (admin + API + reader) | https://nagarik-watch.vercel.app | Vercel (free Hobby) |
| **Admin login** | https://nagarik-watch.vercel.app/admin/login | same |
| Static reader mirror | https://nagarik-watch.pages.dev | Cloudflare Pages |

Cloudflare Workers Free cannot host the full OpenNext bundle (~3.1 MiB gzip vs 3 MiB limit). Vercel already has `DATABASE_URL`, auth secrets, and boot accounts configured.

## Login

1. Open https://nagarik-watch.vercel.app/admin/login
2. Use production env `NEWSROOM_SUPERADMIN_EMAIL` / `NEWSROOM_SUPERADMIN_PASSWORD` (Vercel dashboard → Project → Settings → Environment Variables, or local `apps/web/.dev.vars` if they match)
3. Change the password after first login

Local boot passwords live in `apps/web/.dev.vars` (generated by `pnpm configure:admin`). Production passwords are whatever is set in Vercel env — they may differ.

## Redeploy full app

```bash
vercel deploy --prod --yes
```

## Cloudflare Pages (static reader only)

No admin/API:

```bash
pnpm deploy:web:static
```

## Cloudflare Workers (blocked on Free)

```bash
pnpm deploy:web:cf   # apps/web → nagarik-watch-app OpenNext worker
```

Needs Workers Paid (10 MiB) **or** further bundle cuts. Also needs secrets:

```bash
cd apps/web
pnpm secrets:admin   # AUTH_*, DATABASE_URL, boot passwords → Worker
```

## Payload CMS (`apps/admin`)

Separate Next.js app. Deploy as a second Vercel project using `apps/admin/vercel.json`. When live, set on the reader:

- `CONTENT_SOURCE=payload`
- `PAYLOAD_PUBLIC_SERVER_URL` / `PAYLOAD_ADMIN_URL`
- `PAYLOAD_API_TOKEN`

Until then keep `CONTENT_SOURCE=json` (current).

## Scripts

| Command | Purpose |
|---------|---------|
| `pnpm configure:admin` | Generate local `.dev.vars` |
| `pnpm secrets:admin` | Upload secrets to CF Worker |
| `pnpm deploy:app` | OpenNext Worker deploy (WSL) |
| `pnpm deploy:pages` | Static Pages only |
| `pnpm restore:stash` | Restore admin/api after Pages stash |
