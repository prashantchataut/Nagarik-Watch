## What changed

### 1. Real live-data feeds (replaces mocks)

`apps/web/lib/live/real.ts` — genuine free, no-API-key upstreams, mock fallback on failure:

| Widget  | Upstream                                                                 | Key  | Notes                                                 |
| ------- | ------------------------------------------------------------------------ | ---- | ----------------------------------------------------- |
| Weather | [Open-Meteo Forecast](https://open-meteo.com/en/docs)                    | none | Kathmandu coords, WMO weather-code → condition        |
| AQI     | [Open-Meteo Air Quality](https://open-meteo.com/en/docs/air-quality-api) | none | US AQI                                                |
| Forex   | [Nepal Rastra Bank](https://www.nrb.org.np/api-docs-v1/)                 | none | `/api/forex/v1/rates`, USD/EUR/GBP/etc.               |
| NEPSE   | nepalstock.com homepage                                                  | none | Best-effort scrape, degrades to mock on layout change |

- 5-min in-process cache per key so UtilityStrip + HomeLiveBoard share one fetch.
- `mock:true` badge shows only when a feed has actually degraded — readers see real data by default.
- `UtilityStrip` and `HomeLiveBoard` are now async server components.

### 2. RSS wire aggregation (legal, headline-only)

`packages/ingest/src/index.ts` — aggregates from 9 official Nepali outlets (eKantipur, OnlineKhabar, Ratopati, Setopati, Himalayan Times, Nepali Times, + English editions).

**Policy (enforced in code):** headline + link + published-date only. `bodyHtml` is always empty — Nagarik Watch never republishes body text. Each item links out to the original publisher (`target=_blank rel=noopener`).

- `parseFeed()` — pure, tested (RSS + Atom).
- `fetchAggregatedFeed()` — parallel fetch, dedupe by URL, sort newest-first, 20-item cap.
- `FromWires` homepage section renders it; renders null if every feed is down.

### 4. Footer redesign

4-column layout: brand + social icons (FB/X/YouTube/Telegram/email), sections, about+policy, contact block (address/email/phone/DoIB), inline `NewsletterInline` capture.

### 5. Admin polls manager

`/admin/polls` — `PollsManager` client component: create/edit bilingual poll + options, status draft/open/closed. In-memory only until CMS store wired. `AdminShell` now accepts `children` so other admin pages can override the dashboard body.

### 6. AI features scaffold (Phase 9)

`apps/web/lib/ai/index.ts` — extractive (no-key) implementations:

- `draftSummary`, `draftKeyPoints`, `draftHeadlines`, `draftTags`, `detectDuplicates`, `draftFactCheckScaffold`.

**Hard policy enforced in types:** every result is `AiDraft<T>` with `needsEditorApproval: true` and `status: 'draft'`. AI never auto-publishes. Fact-check returns an empty scaffold the editor fills — AI never invents sources. LLM path is a typed `AiProvider` seam awaiting `AI_PROVIDER_KEY`.

### 7. Algorithm framework (packages/db)

Pure, tested-shape modules:

- `recommend.ts` — content-based (cosine TF), session-based, cold-start, hybrid with diversity + fatigue guardrails, `continueReading`.
- `trending.ts` — velocity, burst ratio, trending score, per-scope filtering, MAB placeholder.
- `notify.ts` — notification scoring, fatigue prevention, quiet hours, per-user quotas.
- `moderation.ts` — lexical toxicity, spam heuristics, Wilson reputation, comment ranking, source-reliability flags.
- `events.ts` — typed analytics event catalog (17 events).

## Manual steps you must complete

1. **Verify RSS feeds render.** Some outlets change their RSS path; check `packages/ingest/src/index.ts` `INGEST_SOURCES` against the live feed and adjust any that 404.
2. **Confirm NEPSE scrape works in your region.** `nepalstock.com` may block Vercel edge IPs; if so it degrades to mock automatically. For reliability, contract a paid NEPSE data vendor and replace `getRealNepse`.
3. **Set social handles.** `Footer.tsx` points at `facebook.com/nagarikwatch` etc. — create those accounts or update the hrefs.
4. **Wire newsletter ESP.** `NewsletterInline` currently shows success without persisting. When ready, POST to `/api/newsletter` and connect `NEWSLETTER_PROVIDER`.
5. **Wire poll persistence.** `PollsManager` is in-memory. To make votes real: add a `polls` Payload collection + `/api/poll/vote` route, then swap `PollOfDay`'s `DEFAULT_POLL` for a server-fetched poll.
6. **Fill PUBLICATION details.** `lib/site.ts` — editor-in-chief name, real address, phone, ownership disclosure once legally confirmed.
7. **Google News application.** Trust pages, sitemap, news-sitemap, JSON-LD are all in place. Submit via [Publisher Center](https://publishercenter.google.com/) after DoIB registration.
