# Product standard

## Positioning

Nagarik Watch should feel like a calm, fast, public-interest newsroom: more legible than crowded legacy portals, more useful than a magazine landing page, and more accountable than an anonymous aggregator.

## Public hierarchy

- Masthead: identity, date, search, language, account, essential utilities.
- Primary navigation: a restrained set of durable desks.
- Live rail: breaking news only when editorially activated.
- Homepage: one decisive lead, a compact latest stream, strong desk modules, province access, public-service utilities, and visible trust cues.
- Article: category, headline, deck, provenance, byline, timestamps, correction state, media credit, readable body, related coverage, and restrained engagement.

## Visual rules

- Use editorial contrast, not a field of cards.
- Use borders and whitespace for grouping; reserve elevated surfaces for tools and actions.
- Use one main brand red, ink neutrals, and one utility accent.
- Avoid excessive pills, gradients, shadows, rounded containers, and repeated icon-only controls.
- Headlines must wrap naturally in Nepali. Do not force English-like tight line-height.
- Mobile is not a compressed desktop. Prioritize latest, lead, search, and section navigation.

## Route standard

A route is launch-worthy only when it has all of:

1. real data or an honest state
2. unique user value
3. working navigation and metadata
4. responsive and keyboard behavior
5. loading, empty, error, and permission states
6. an owner and measurable success signal

Consolidate routes that are only aliases or twenty-line wrappers unless the URL has durable product value.
