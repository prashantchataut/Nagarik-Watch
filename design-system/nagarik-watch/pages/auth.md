# Auth override

Overrides `MASTER.md` for `/auth/login`, `/auth/signup`, `/auth/register`, profile, and invite flows.

## Register

Calm **brand** editorial split: form column + restrained crimson editorial panel. Not marketing hero, not admin cockpit.

## Structure

1. Single-column form on narrow viewports
2. Desktop: form + editorial aside (mission line, no fake metrics)
3. Google OAuth control visible but disabled until env flag is true
4. Clear path back to reader signup for journalist login pages
5. Honest copy: staff roles are provisioned, not self-serve

## Anti-patterns

- Fake OAuth buttons
- Paywall or premium upsell on auth surfaces
- Glass cards, dashed empty placeholders
- Em dashes in UI copy
- Side-stripe form accents

## Tokens

Use Civic Crimson `--brand` / `--brand-strong` and `--surface` backgrounds only. No alternate palette from generic search results.
