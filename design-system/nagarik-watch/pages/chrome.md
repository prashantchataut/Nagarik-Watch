# Chrome override

Overrides `MASTER.md` for public masthead, topics strip, mobile drawer, bottom nav, and footer.

## Register

Civic Crimson **brand** register: confident editorial identity (Ratopati / OnlineKhabar / eKantipur density), not SaaS chrome.

## Structure (Ratopati-led bands)

1. **Utility** — BS date · Kathmandu; tools (utilities/पात्रो, contact); account, saved, search, theme
2. **Brand** — mobile menu · centered wordmark · solid locale control (`नेपाली` / `EN`)
3. **Primary** — always visible (horizontal scroll on mobile): Home · CMS categories · Provinces · Fact check; trailing desktop CTAs for Utilities + Latest
4. **Topics strip** — grey rail of curated hubs + live tags (chips allowed here only)
5. **Bottom nav (mobile)** — Home · Latest · Search · Sections (opens drawer) · Account
6. **Footer** — newspaper columns: CMS sections, desks, about/trust, contact + newsletter

Condensed-on-scroll: hide utility + topics; **keep brand + primary**.

## Anti-patterns

- Hiding primary category nav on mobile
- Launch-readiness or CMS env labels on public pages
- Glass / backdrop-blur on reader chrome
- Pill clusters in primary navigation (topics strip only)
- Cloning Ratopati Games / Radio as fake chrome
- Membership CTAs when Option A is active

## Motion

Transform and opacity only. Drawer slides; no layout-thrashing animations.
