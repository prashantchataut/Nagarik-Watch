# Chrome override

Overrides `MASTER.md` for public masthead, secondary nav, mobile drawer, and footer.

## Register

Civic Crimson **brand** register: confident editorial identity, not SaaS chrome or raw ui-ux-pro-max palettes.

## Structure

1. Masthead: date line, wordmark, account entry, locale + theme toggles
2. Secondary nav: section links as typographic desk labels (underline on hover, not pills)
3. Mobile drawer: reader-first links; account / sign-in always visible
4. Bottom nav (mobile): latest, trending, saved, search
5. Footer: trust links, section directory, publication identity when configured

## Anti-patterns

- Launch-readiness or CMS env labels on public pages
- Glass / backdrop-blur on reader chrome
- Pill clusters for primary navigation
- Side-stripe accents on nav items
- Membership CTAs when Option A is active

## Motion

Transform and opacity only. Drawer slides; no layout-thrashing animations.
