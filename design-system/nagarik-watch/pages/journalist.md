# Journalist override

Overrides `MASTER.md` for `/journalist/*` contributor desk.

## Register

**Restrained desk** aligned with admin, but copy speaks to contributors and freelancers. Civic Crimson, not ui-ux-pro-max default blues.

## Structure

1. Desk home: submission status, drafts, and guidance in prose blocks
2. Forms: flat bordered fields, explicit labels
3. Empty states: honest ("No drafts yet"), no demo rows
4. Login explains invite / editor approval path; link to reader signup

## Anti-patterns

- Self-serve newsroom role elevation from public UI
- Dashed empty cards or fake seed content
- Glass panels, pill nav clusters
- Em dashes in UI copy

## Relationship to auth

Same Better Auth session as readers; role gate controls access. Visual language matches auth split layout where login is shared.
